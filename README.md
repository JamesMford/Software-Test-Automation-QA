# Software-Test-Automation-QA
How can I ensure that my code, program, or software is functional and secure?
I can ensure that my software is functional and secure by testing it. Static and dynamic testing, as well as unit, integration, and regression testing of written code is an essential element to the continuous integration/continuous development (CI/CD) pipeline designed to catch bugs and defects early, improve the quality and reliability of software, shorten the length of time to production, and increase the frequency of releases.

How do I interpret user needs and incorporate them into a program?
User needs for a system are gathered in the design phase and guide developers to the core features necessary to make a system useful to its future users. Core features are system requirements that are then prioritized to decide which ones get built. Requirements should be specific, measurable, achievable, and relevant.

How do I approach designing software?
I approach the design of software by first defining user goals and turning them into system requirements. Next is the design phase, where requirements are turned into core system features. Next comes the iterative part of the process where the features are built and refined in repeated cycles, adapting and redesigning them as necessary, until all features have qualified as "done", and all unit, integration, and regression tests have passed green.
